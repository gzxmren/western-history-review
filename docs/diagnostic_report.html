现有复习笔记的认知层次覆盖

认知层次 现有复习笔记中的体现 覆盖率
recall 科学家、思想家表格、年份、条约名称 ✅ ~85%

explain 因果关系描述（5大原因、Why Britain） ⚠️ ~40% — 有描述但缺方法框架
analyze 影响分析（经济/社会/技术三方面） ⚠️ ~30% — 有列表但缺分析方法
compare review_guide.md 末尾提到常考对比题 ❌ ~5% — 仅有提示，无系统性框架
evaluate 没有独立的评价方法指引 ❌ ~0%

深度缺口总结

缺口 严重程度 影响
遗漏 compare 题型 🔴 严重 考试中若有"Compare X and Y"，学生完全没练过
缺 evaluate 方法框架 🟡 中等 DBQ Q4 是 evaluate 题，但没有对应的答题方法指导
explain 层欠缺系统性 🟡 中等 笔记中的因果解释以列表为主，没有因果链方法
史料分析缺 STAR 框架 🟡 中等 模拟题给了史料，但学生没有独立的分析方法
