如何用这份索引

1. 看你现在到哪个层次（recall → understand → explain → analyze → compare → evaluate）

3. 如果考试会考 evaluate 但你只复习到 recall → 去翻对应的技能框架文件

复习惯策略建议

按认知层次的时间分配

recall（知道）：    20% 时间  ← 你现在花了 80% 时间在这儿
understand（理解）：15% 时间
explain（解释）：   20% 时间  ← 考试中资料题的核心
analyze（分析）：   20% 时间  ← 需要结合史料进行
compare（比较）：   10% 时间  ← 新补题型，重点练习
evaluate（评价）：  15% 时间  ← 最高分题型
